NIST SP 800-90B

Recommendation for the Entropy Sources Used for Random Bit Generation

Share to Facebook Share to X Share to LinkedIn Share ia Email

    Documentation     Topics

Date Published: January 2018

Planning Note (05/29/2025):

Two errata have been identified, which will be corrected in a future update/revision of this publication. For details, see this errata (potential updates) file.


Author(s)

Meltem Sönmez Turan (NIST), Elaine Barker (NIST), John Kelsey (NIST), Kerry McKay (NIST), Mary Baish (NSA), Michael Boyle (NSA)

Abstract

This Recommendation specifies the design principles and requirements for the entropy sources used by Random Bit Generators, and the tests for the validation of entropy sources. These entropy sources are intended to be combined with Deterministic Random Bit Generator mechanisms that are specified in SP 800-90A to construct Random Bit Generators, as specified in SP 800-90C.
