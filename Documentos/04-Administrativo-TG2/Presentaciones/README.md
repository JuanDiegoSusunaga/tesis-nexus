# Preparación de sustentación TG2

El [guion de sustentación](Guion-Sustentacion-TG2.md) organiza la exposición y las preguntas. Es un borrador de contenido; todavía no se registra una presentación final ni un ensayo realizado.

Usar el [balance de objetivos](../Entrega-Final/Balance-Objetivos-TG2.md), el [manuscrito vigente](../../01-Manuscrito/README.md) y sus tres figuras como fuentes. Cada cifra de una futura diapositiva debe conservar referencia a su tabla o informe y sus condiciones experimentales.

Antes de preparar la versión final, incorporar la duración asignada por el programa, el dictamen académico y las correcciones que de él resulten.
