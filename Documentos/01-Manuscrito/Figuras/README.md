# Figuras del manuscrito

Elaboración propia a partir de los capítulos. Son esquemas conceptuales; no representan resultados experimentales nuevos.

| Figura | Contenido | Función generadora |
|---|---|---|
| 1.1 | Secuencia del argumento | `arco()` |
| 3.1 | Arquitectura dual de referencia | `arquitectura()` |
| 5.1 | Gestor R3: bloqueo de derivación/firma y validación antes de instalar la nueva época | `ciclo()` |

Fuente editable: [generar_figuras_manuscrito.py](../../../scripts/generar_figuras_manuscrito.py). Ejecutar desde la raíz: `python scripts/generar_figuras_manuscrito.py`.

Cada figura se guarda en SVG, PDF vectorial y PNG de 320 ppp. El SVG incorpora las letras como trazados para que Chrome conserve la misma tipografía de las imágenes insertadas en Word. El ancho de impresión es 6,5 pulgadas y el texto, 10 puntos. Las leyendas y notas de alcance se editan en los capítulos.
